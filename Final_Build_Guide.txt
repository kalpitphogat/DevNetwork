2.2  Agent Node Flow

Step-by-step execution:

User submits company profile + up to 5 competitors via the frontend form

FastAPI creates run_id, pushes to Redis queue, opens SSE stream for live updates

Research Planner node calls Nemotron: "Generate a prioritised research plan with 5–7 specific queries"

Parallel Data Fetcher nodes execute: Tavily web search, HackerNews API, GitHub job signals, pricing page scraper

Each result stored with metadata: source URL, timestamp, fetch status (success / failed / partial)

Synthesizer node calls Nemotron: produces full briefing with [VERIFIED] / [INFERRED] / [UNVERIFIED] tags on every claim

Confidence Scorer validates VERIFIED claims have real source URLs; computes section-level scores

Briefing pushed to frontend via SSE streaming — user sees live progress throughout

TrueFoundry Gateway detects non-2xx or timeout after 5 seconds

Auto-fallback to Claude Sonnet (configurable secondary)

Briefing header shows: "Primary model unavailable — completed via fallback. Verify synthesis quality."

Run completes — user gets output, not a frozen spinner

Failure Scenario 2 — Data Source MCP Server Down

Fetcher node catches exception, marks source UNAVAILABLE in metadata

Agent continues with available sources — never crashes the run

Affected briefing section shows: "[DATA GAP] Pricing data unavailable for Competitor X — last known: $99/mo (3 days ago)"

Confidence score for that section auto-drops to INFERRED or UNVERIFIED

Failure Scenario 3 — Mid-run API Timeout / Crash

Agent state checkpointed in Redis after every node completes

On restart: resumes from last successful checkpoint, not from scratch

User sees "Resuming from checkpoint..." in the live WebSocket feed

7.2  Inspiration

Every founder we spoke to spends 4–6 hours per week tracking competitors manually. Worse, when they try to use AI agents for this, those agents fail silently — returning partial output with no warning, leaving the user with a false sense of completeness. We built SentinelBrief to solve both problems: automate the research loop, and make the agent genuinely resilient to infrastructure chaos.

7.3  What It Does

SentinelBrief takes a company profile and up to five competitors, then autonomously researches funding events, product changes, pricing updates, and hiring signals across the web. It synthesizes findings into a structured weekly briefing, tagging every claim as VERIFIED (source cited), INFERRED (cross-referenced), or UNVERIFIED (model knowledge only). Every LLM call routes through TrueFoundry AI Gateway — so if Nemotron browns out mid-run, the agent automatically falls back to a secondary model and continues. No crashes. No silent failures. No spinner that never resolves.

7.4  How We Built It

An asyncio-based orchestrator manages the multi-node agent pipeline with Redis checkpointing for crash recovery. Nemotron on Crusoe Cloud Managed Inference handles research planning and synthesis — its multi-step reasoning produces significantly better structured output than general-purpose models. TrueFoundry AI Gateway sits in front of every LLM call, handling routing, fallback, and retry logic. The frontend is Next.js with real-time progress via SSE streaming. Tavily API provides web search with source URLs, feeding directly into the VERIFIED confidence tagging pipeline.

7.5  Challenges

Getting Nemotron to consistently emit structured confidence tags required significant prompt engineering — the model naturally wants to write prose, not tagged claims. We solved this with a two-pass approach: synthesis in pass one, tag validation and correction in pass two. The checkpoint-based resume was also non-trivial since the orchestrator's state serialization required custom handling for our source metadata objects.
